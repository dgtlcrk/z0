# Code of Conduct

## Our commitment

The z0 project is committed to providing a respectful, welcoming, and
productive environment for contributors and users of all experience levels.

## Expected behavior

Project participants are expected to:

- Communicate respectfully and constructively
- Welcome questions and differing experience levels
- Focus criticism on ideas and technical work rather than individuals
- Accept feedback professionally
- Give credit for the work and ideas of others
- Protect private or sensitive information
- Follow responsible network-testing practices

## Unacceptable behavior

The following behavior is not acceptable:

- Harassment, threats, or personal attacks
- Discriminatory or demeaning language
- Deliberate intimidation
- Publishing another person's private information
- Sharing credentials, private keys, or sensitive logs
- Encouraging unauthorized access or network activity
- Repeated disruption of project discussions
- Any conduct that would reasonably make others feel unsafe or unwelcome

## Scope

This code of conduct applies to:

- GitHub issues
- Pull requests
- Code reviews
- Discussions
- Project-related IRC channels
- Other spaces representing the z0 project

## Enforcement

Maintainers may edit or remove comments, commits, issues, and other
contributions that violate these standards.

Maintainers may also temporarily or permanently restrict participation when
necessary to protect the project community.

## Reporting

Report serious conduct concerns privately to the project maintainer rather
than posting them publicly.

Reports should include relevant context while excluding credentials, private
keys, access tokens, and unrelated personal information.
